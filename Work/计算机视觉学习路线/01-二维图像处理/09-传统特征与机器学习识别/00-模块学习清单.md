# 模块 09：传统特征与机器学习识别

## 1. 模块目标

将二维图像转换为可解释特征，建立分类、判别或异常检测的传统机器学习基线，为后续模型提供比较对象。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 09.1 | 任务定义 | 分类、二分类、多分类、异常和对象级判断 | 写清输入与标签 |
| 09.2 | 数据与标签 | 样本单位、标签质量、类别平衡和元数据 | 检查标签分布 |
| 09.3 | 统计特征 | 均值、方差、分位数、直方图和区域属性 | 构造基础特征表 |
| 09.4 | 形状特征 | 面积、周长、圆度、长宽比和矩 | 识别简单形状 |
| 09.5 | 纹理特征 | LBP、共生统计和局部对比 | 区分纹理类别 |
| 09.6 | HOG | 梯度方向直方图和局部归一化 | 识别方向结构 |
| 09.7 | 局部描述子聚合 | SIFT/ORB、匹配统计和视觉词袋思想 | 构造图像级描述 |
| 09.8 | 特征标准化 | 尺度差异、训练统计和数据泄漏 | 比较标准化前后 |
| 09.9 | KNN | 距离、邻居数和特征尺度 | 建立最小分类基线 |
| 09.10 | SVM | 分类边界、核和正则化 | 比较线性与非线性 |
| 09.11 | 决策树与随机森林 | 特征切分、非线性和特征重要性 | 建立树模型基线 |
| 09.12 | 异常检测 | 正常样本建模、距离和孤立方法 | 只用正常样本训练 |
| 09.13 | 模型评价 | 混淆矩阵、Precision、Recall、F1 和 PR 曲线 | 独立测试集评价 |

## 3. 数据划分原则

- 按真实样本主体、批次或采集会话划分。
- 相邻裁剪块不能随机分到训练与测试两侧。
- 标准化参数只从训练集计算。
- 测试集不参与阈值选择和特征筛选。
- 类别不平衡时同时关注 Precision、Recall 和 PR 曲线。

## 4. 关键认识

- 特征应与任务假设对应，不是数量越多越好。
- 传统模型在小数据、可解释需求和稳定成像条件下仍有价值。
- 特征标准化和样本划分错误会造成虚高结果。
- 分类准确率不能替代对漏检成本的分析。

## 5. 模块产出

- 图像级特征表。
- 至少三个传统模型的统一对比。
- 混淆矩阵和主要指标。
- 特征重要性或可解释性记录。
- 错误分类样本集。

## 6. 模块验收

- 能从问题定义构造合适的特征。
- 能建立无数据泄漏的训练与测试流程。
- 能解释不同模型的主要差异。
- 能给出传统识别基线和失败边界。
