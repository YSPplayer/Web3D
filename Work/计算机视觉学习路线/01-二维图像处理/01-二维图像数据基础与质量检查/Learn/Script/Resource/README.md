# 二维图像数据基础学习资源

本目录只提供第一课需要的图像资源和使用说明，不包含示例代码或答案。

建议先复制资源文件再做实验，保留本目录中的原始文件不变。

## 2. 已验证的关键属性

### 04-gray16-gradient-saturation.tif

- 实际像素格式：gray16le。
- 最小值：0。
- 最大值：65535。
- 不同灰度值数量：2291，超过 8 位图像最多 256 个灰度的范围。
- 图像包含水平渐变、暗圆、亮圆、上下区域差异、细微周期变化以及明确的最暗和最亮区域。

### 05-gray16-container-from-gray8.tif

- 实际像素格式：gray16le。
- 最小值：0。
- 最大值：65535。
- 不同灰度值数量：256。
- 该文件故意由 8 位灰度源扩展到 16 位容器，用于证明文件 dtype、容器位深和有效灰阶数量是三个不同概念。

### 03-rgba8-alpha-shapes.png 与 06-alpha-mask8.png

- 03 文件实际包含 RGBA 四个通道。
- Alpha 最小值为 0，最大值为 255。
- Alpha 通道具有 256 个不同取值，既有完全透明、完全不透明，也有部分透明像素。
- 06 文件是 03 文件 Alpha 通道的独立单通道参考。

### 08-gray8-full-range-ramp.png

- 最小值：0。
- 最大值：255。
- 不同灰度值数量：256。
- 从左到右每一列对应一个灰度等级。

## 3. 推荐学习顺序

### 第一步：认识 shape、dtype 和灰度范围

使用：

- 01-gray8-tone-shapes.png
- 08-gray8-full-range-ramp.png

观察：

- 图像高度、宽度和单通道 shape。
- uint8 的最小值、最大值和灰度数量。
- 真实场景灰度分布与规则渐变分布的区别。
- 全图、局部区域和背景区域的统计差异。

### 第二步：认识 RGB/BGR 与通道

使用：

- 02-rgb8-channel-shapes.png
- 07-rgb8-coordinate-corners.png

观察：

- 三通道 shape。
- 分别查看红、绿、蓝通道。
- 交换 RGB/BGR 后红色和蓝色区域如何变化。
- 灰色、白色和黑色区域在三个通道中的关系。

### 第三步：认识坐标与方向

使用：

- 07-rgb8-coordinate-corners.png

已知视觉位置：

- 左上：红色。
- 右上：绿色。
- 左下：蓝色。
- 右下：黄色。
- 中心：白色。

用它检查：

- 数组第一维和第二维分别控制什么方向。
- 左上角、右下角和中心像素的索引。
- row/column 与 u/v 的对应关系。

### 第四步：认识 Alpha 与有效区域

使用：

- 03-rgba8-alpha-shapes.png
- 06-alpha-mask8.png

观察：

- 四通道 shape。
- Alpha 为 0、介于 0 和 255、等于 255 的区域。
- 把 Alpha 转成前景掩膜时，不同阈值产生什么区别。
- 透明背景为什么不应自动当成黑色图像内容。

### 第五步：认识 8 位与 16 位

使用：

- 04-gray16-gradient-saturation.tif
- 04-preview-gray16-gradient.png
- 05-gray16-container-from-gray8.tif
- 08-gray8-full-range-ramp.png

比较：

- dtype 与数值范围。
- 8 位和 16 位的不同灰度数量。
- 同为 16 位 TIFF 的两个文件为什么有效灰阶数量完全不同。
- 为什么预览 PNG 只能用于观看，不能代表 16 位源数据。
- 直接转成 8 位与按显示范围映射有什么区别。

## 4. 建议填写的数据说明项

对每个文件至少记录：

- 文件名与格式。
- 宽度、高度和 shape。
- dtype 与通道数。
- 通道顺序。
- 最小值、最大值、均值和中位数。
- 1%、5%、95%、99% 百分位。
- 不同像素值数量。
- 等于最小值和最大值的像素数量。
- 是否包含 Alpha。
- 背景、无效和有效区域规则。
- 显示范围与色表。
- 是否适合进入下一处理步骤。

## 5. 使用边界

- 不要覆盖原始资源。
- 不要仅根据文件扩展名推断 dtype 和通道。
- 不要使用 04 的预览 PNG 代替 16 位 TIFF。
- 不要把透明背景直接解释成黑色目标。
- 不要把 05 的 16 位容器误认为具有大量新细节。
- 显示效果变化时，先确认原始像素是否真的变化。

## 6. 资源来源说明

- 01、02、03 的主体图像由内置图像生成工具生成。
- 04、07、08 是为了保证数值、位深和位置准确而制作的规则测试图。
- 05 是专门构造的位深对照文件。
- 06 从 03 的 Alpha 通道中提取，用作检查参考。
- 所有交付资源均已检查文件存在性、尺寸、通道和像素格式。
