# 模块 06：形态学与连通区域

## 1. 模块目标

使用结构元素和连通关系清理二维掩膜，并将像素结果整理为可以单独统计和测量的对象。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 06.1 | 结构元素 | 形状、尺寸、方向和观察尺度 | 比较圆、方、十字和线形核 |
| 06.2 | 腐蚀 | 收缩、去小点和断开细连接 | 观察目标尺寸变化 |
| 06.3 | 膨胀 | 扩张、填小缝和目标粘连 | 观察对象合并 |
| 06.4 | 开运算 | 去除小前景和保持大结构 | 测试噪点掩膜 |
| 06.5 | 闭运算 | 填小孔、连接间隙和边界变化 | 测试断裂区域 |
| 06.6 | Top-hat/Black-hat | 局部亮结构和暗结构 | 提取小亮点与暗点 |
| 06.7 | 连通域 | 4/8 连通、标签、面积和外接框 | 提取多个对象 |
| 06.8 | 距离变换 | 到边界的距离和区域中心 | 计算中心与局部厚度 |
| 06.9 | 骨架化 | 中轴、分支和拓扑 | 提取细长目标中心线 |
| 06.10 | 分水岭 | 标记、距离峰和粘连对象分离 | 分离接触对象 |
| 06.11 | 对象级过滤 | 面积、位置、长宽比和形状规则 | 清除对象级误检 |

## 3. 关键认识

- 结构元素尺寸定义会被删除、连接或保留的目标尺度。
- 形态学会改变面积和边界。
- 4 连通和 8 连通可能得到不同对象数量。
- 清理掩膜应针对已知问题，不能只为了图形整齐。

## 4. 模块产出

- 结构元素选型表。
- 每种形态学操作前后对比。
- 连通对象属性表。
- 过度处理导致目标消失或粘连的失败样本。

## 5. 模块验收

- 能根据目标像素尺寸选择结构元素。
- 能解释不同连通规则。
- 能量化处理前后的面积、周长和对象数变化。
- 能报告掩膜清理对边界测量的影响。
