# 模块 10：二维深度学习识别

## 1. 模块目标

掌握二维视觉模型的完整训练闭环，能够完成分类、分割、检测或异常识别，并与传统基线公平比较。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 10.1 | Tensor 与批次 | NCHW、dtype、设备和 batch | 检查一批输入 |
| 10.2 | Dataset/DataLoader | 样本读取、标签、shuffle 和并行加载 | 构造最小数据集 |
| 10.3 | 自动微分 | 前向、损失、反向和参数更新 | 训练最小分类器 |
| 10.4 | 卷积网络 | 卷积、激活、池化和感受野 | 观察特征图尺寸 |
| 10.5 | 归一化与正则化 | BatchNorm、Dropout、权重衰减 | 比较训练与验证曲线 |
| 10.6 | 残差网络 | 残差连接和特征层级 | 使用小型预训练骨干 |
| 10.7 | 迁移学习 | 冻结、微调和学习率 | 小数据分类实验 |
| 10.8 | 图像分类 | 类别、Logits、Cross Entropy 和 Top-k | 建立分类模型 |
| 10.9 | U-Net 分割 | 编码器、解码器、跳跃连接和像素输出 | 完成二值分割 |
| 10.10 | 目标检测 | 框、类别、IoU、NMS 和匹配 | 使用预训练模型微调 |
| 10.11 | 异常识别 | 监督、弱监督和仅正常样本方法 | 构建异常热图 |
| 10.12 | 数据增强 | 翻转、裁剪、颜色变化和标签同步 | 检查增强是否合理 |
| 10.13 | 损失函数 | CE、BCE、Dice 和 Focal Loss | 比较类别不平衡任务 |
| 10.14 | ViT 基础 | patch、token、自注意力和预训练 | 使用预训练模型实验 |
| 10.15 | 过拟合与调参 | 学习率、容量、早停和验证集 | 分析训练曲线 |

## 3. 推荐顺序

1. 先完成一个很小的分类闭环。
2. 再学习迁移学习和预训练模型。
3. 根据实际任务选择分割、检测或异常识别。
4. 先理解 CNN，再学习 ViT。
5. 每个模型都与传统基线比较。

## 4. 关键认识

- 模型效果通常首先受数据定义、标签和划分影响。
- 小数据场景优先考虑迁移学习。
- 数据增强必须保持标签和业务语义正确。
- 训练损失降低不代表测试效果提高。
- 可视化热图不能自动证明模型关注了正确原因。

## 5. 模块产出

- 一个可复现的最小训练程序。
- 训练、验证与测试曲线。
- 传统基线和神经网络对比表。
- 混淆矩阵或分割结果。
- 错误预测样本与原因分类。
- 最佳模型和完整预处理配置。

## 6. 模块验收

- 能解释从输入到损失再到参数更新的流程。
- 能正确区分 train、eval 和无梯度推理。
- 能避免样本泄漏。
- 能使用独立测试集报告结果。
- 能说明模型在哪些条件下失败。
