# 二维图像处理：阶段总览

## 1. 阶段定位

本阶段从二维图像的数据基础开始，依次学习图像增强、滤波、局部结构、分割、对象测量、图像对齐、传统识别、二维深度学习、评价和推理。

学习重点不是记忆 API，而是建立一套稳定的判断流程：

    先确认数据
      → 再选择处理方法
      → 再提取区域或特征
      → 再完成识别或测量
      → 最后用指标和失败样本验证

## 2. 阶段目标

完成本阶段后，应当能够：

1. 正确读取普通照片、工业灰度图和高位深图像。
2. 分清原始数值、增强结果和显示结果。
3. 根据噪声类型选择滤波方法。
4. 使用边缘、阈值、形态学和连通域提取对象。
5. 从轮廓中计算面积、周长、方向和二维尺寸。
6. 通过模板、相位或局部特征完成二维对齐。
7. 建立传统特征加分类器的识别基线。
8. 使用二维神经网络完成分类、分割、检测或异常识别。
9. 通过正确数据划分和任务指标证明结果有效。
10. 完成模型导出、推理和性能测试。

## 3. 学习工具

- NumPy：数组检查和最小实验。
- OpenCV：二维图像处理与传统视觉。
- Matplotlib：图像、直方图、曲线和对比结果。
- Pillow、imageio 或 tifffile：补充图像读取。
- scikit-learn：传统机器学习。
- PyTorch 与 torchvision：二维深度学习。
- ONNX Runtime：模型推理和一致性测试。

第一轮只为具体任务使用这些工具，不并行学习多个功能相同的库。

## 4. 必要知识随用随学

不单独设置数学阶段，但在对应模块补充：

- 卷积核和加权和：在滤波模块学习。
- 有限差分：在梯度模块学习。
- 直方图与概率分布：在增强和阈值模块学习。
- 矩阵变换：在二维对齐模块学习。
- 特征标准化和分类边界：在传统识别模块学习。
- 梯度下降和反向传播：在深度学习模块学习。

## 5. 每个模块的固定产出

- 算法学习卡。
- 合成图像实验。
- 真实图像实验。
- 参数与指标表。
- 成功样本。
- 失败样本。
- 本模块结论。

## 6. 阶段最终产出

完成一个纯二维综合项目，例如：

- 二维表面图像缺陷分割。
- 工件轮廓识别与尺寸测量。
- 二维纹理分类。
- 二维目标定位或异常检测。

项目必须同时包含数据说明、传统基线、指标、失败样本和可重复推理流程。
