# 模块 04：梯度、边缘与角点

## 1. 模块目标

理解二维图像中的局部灰度变化，能够从像素邻域计算梯度、边缘和角点，并判断检测结果是否稳定。本模块重点不是调用现成接口，而是弄清楚“平滑—求导—筛选—定位”的完整过程，为后续轮廓、分割、特征匹配和目标分析打基础。

完成后应能够：

- 解释一阶导数、二阶导数、梯度幅值和梯度方向。
- 手写 Sobel 梯度，并正确处理核、通道和图像边界。
- 解释噪声与平滑尺度为什么会影响边缘。
- 分步骤实现基础 Canny 边缘检测。
- 理解角点与边缘、平坦区域的区别。
- 实现基础 Harris 角点，并理解 Shi-Tomasi 的判断方式。
- 使用合成真值、重复定位和视觉结果评价算法，而不是只看“检测数量”。

## 2. 前置检查

开始本模块前，至少确认：

- [ ] 能说明像素邻域、卷积核、锚点和归一化。
- [ ] 能手工计算一个 `3×3` 邻域的加权和。
- [ ] 知道 Gaussian 平滑的核大小和 sigma 分别控制什么。
- [ ] 知道 constant、replicate、reflect 边界模式的区别。
- [ ] 理解噪声会产生高频变化，边缘检测前可能需要平滑。
- [ ] 能区分原始算法数据与为了显示而归一化的图像。

## 3. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 04.1 | 一阶差分 | 前向差分、中心差分、水平和垂直变化 | 在阶跃、斜坡和常量图上手算差分 |
| 04.2 | Sobel 梯度 | `Gx`、`Gy`、平滑与微分组合 | 检测水平、垂直和斜向边缘 |
| 04.3 | Scharr 对比 | Sobel 的方向误差与 Scharr 权重 | 在旋转线条上比较方向响应 |
| 04.4 | 幅值与方向 | `sqrt(Gx²+Gy²)`、近似幅值、`atan2` | 分别可视化 Gx、Gy、幅值和方向 |
| 04.5 | 二阶变化 | Laplacian、零交叉、噪声敏感性 | 比较平滑前后的 Laplacian |
| 04.6 | 非极大值抑制 | 沿梯度方向保留局部最大值 | 比较抑制前后的边缘宽度 |
| 04.7 | 双阈值与连接 | 强边缘、弱边缘和滞后连接 | 改变高低阈值观察断裂与误检 |
| 04.8 | Canny | Gaussian、梯度、NMS、双阈值和连接 | 分步显示每个中间结果 |
| 04.9 | Harris 角点 | 结构张量、响应值、阈值和局部极大值 | 在棋盘格、直线和纯色区域测试 |
| 04.10 | Shi-Tomasi | 最小特征值、角点质量和最小间距 | 与 Harris 比较角点位置和稳定性 |
| 04.11 | 稳定性评价 | 尺度、噪声、旋转、亮度变化和重复定位 | 对同一图像扰动后重新检测 |
| 04.12 | 边缘评价 | Precision、Recall、定位误差和连通性 | 与合成图像的已知边界比较 |

## 4. 推荐学习顺序

1. 使用常量、阶跃、斜坡、水平线、竖直线和斜线构造可预测输入。
2. 手算一处中心差分和一处 Sobel 输出。
3. 实现 `Gx`、`Gy`，再计算幅值和方向。
4. 比较不平滑、轻度平滑和过度平滑后的梯度。
5. 实现非极大值抑制，观察宽边缘如何变细。
6. 实现双阈值和弱边缘连接，组成完整 Canny。
7. 学习二阶导数与 Laplacian，理解其噪声敏感性。
8. 从局部结构张量理解 Harris，再比较 Shi-Tomasi。
9. 最后进行阈值、尺度、噪声和重复定位实验。

## 6. 在现有 HTML 项目中的体现

继续复用 Vue/Canvas 项目，不要求为每个算子创建独立页面。建议增加一个分析页签或控制卡片组。

### 梯度与边缘控制

- 算子：Sobel、Scharr、Laplacian、Canny。
- 核尺寸：3、5、7；不支持的组合应禁用。
- Gaussian sigma。
- 显示内容：Gx、Gy、幅值、方向、NMS、最终边缘。
- Canny 低阈值和高阈值。
- 边界模式：constant、replicate、reflect。
- 应用和复位按钮。

### 角点控制

- 方法：Harris、Shi-Tomasi。
- 邻域窗口、平滑 sigma、响应阈值。
- Harris 参数 `k`。
- 最大角点数量和最小角点间距。
- 在结果图上叠加角点标记，并保留未绘制标记的算法结果。

### 建议数据状态

```js
imageDataRoot        // 不可覆盖的预览基准图
imageDataGray        // 梯度算法使用的灰度输入
gradientX            // 有符号浮点梯度
gradientY            // 有符号浮点梯度
gradientMagnitude    // 浮点幅值
gradientDirection    // 浮点方向
edgeMask             // 最终二值边缘
cornerResponse       // 浮点角点响应
cornerPoints         // 角点坐标和响应值
displayImageData     // 仅用于 Canvas 显示
```

必须避免把归一化后的梯度显示图重新作为算法输入，也不要用角点标记覆盖原始图像数据。

## 7. 最小实验矩阵

| 实验 | 输入 | 改变变量 | 固定条件 | 至少观察 |
|---|---|---|---|---|
| 梯度方向 | 水平、垂直、斜向阶跃 | 边缘方向 | 算子和尺度 | Gx、Gy、幅值和方向 |
| 算子比较 | 旋转线条 | Sobel/Scharr | 相同输入和边界 | 方向响应一致性 |
| 噪声影响 | 干净图和含噪图 | 平滑 sigma | Sobel 参数 | 伪边缘与真实边缘损失 |
| Canny 阈值 | 同一平滑图 | 高低阈值 | 其他步骤不变 | 断裂、误检和连通性 |
| Laplacian | 干净/含噪图 | 是否预平滑 | 相同核 | 双边响应和噪声放大 |
| Harris | 棋盘和直线 | 响应阈值、k | 相同窗口 | 角点、边缘和重复点 |
| 角点稳定性 | 原图与轻微扰动图 | 噪声、亮度或位移 | 检测参数 | 重复检测比例和位置偏差 |

## 8. 关键认识

- 边缘是局部强变化，不自动等于完整对象轮廓。
- 梯度方向表示变化最快的方向，通常与边缘延伸方向垂直。
- 噪声也会产生高梯度，因此检测前通常需要适度平滑。
- 平滑尺度决定观察尺度，阈值决定检测灵敏度。
- 非极大值抑制负责定位和变细，双阈值负责筛选和连接。
- Laplacian 对噪声敏感，二阶响应不能只看亮度归一化后的显示图。
- 角点适合定位和匹配，但低纹理区域可能没有稳定角点。
- 检测数量更多不代表效果更好，错误响应、定位偏差和重复点同样重要。

## 10. 模块验收

### 合格：允许进入模块05

- 能手算并实现基础 Sobel，正确得到 Gx、Gy、幅值和方向。
- 能解释平滑尺度对噪声和边缘定位的影响。
- 能分步骤实现或完整解释 Canny 的主要流程。
- 能实现 Harris，完成阈值、非极大值抑制和角点标记。
- 能区分平坦区、边缘区和角点区域。
- 至少完成一组有真值边缘实验和一组角点稳定性实验。
- 能说明至少三个失败案例及其原因。

### 良好

- 能比较 Sobel 与 Scharr 的方向响应。
- 能比较多组 Canny 阈值和 Gaussian sigma。
- 能比较 Harris 与 Shi-Tomasi 的定位和重复性。
- 结果同时包含中间数据、视觉观察和基础指标。
- 能确保浮点算法数据、二值结果和显示图互不覆盖。

### 优秀

- 完成方向插值形式的非极大值抑制。
- 使用边界距离或容差匹配评价边缘定位。
- 比较角点在噪声、旋转、缩放或亮度变化下的稳定性。
- 能分析运行时间、内存分配和浏览器交互性能。
- 能说明当前边缘或角点结果会怎样影响后续轮廓、匹配或分割任务。

不要求为了达到优秀而堆叠更多算子。能够保留正确的中间数据、解释参数影响、发现失败结果并形成可重复证据，比算子数量更重要。
