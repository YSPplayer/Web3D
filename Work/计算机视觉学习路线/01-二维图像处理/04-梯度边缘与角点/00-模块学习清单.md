# 模块 04：梯度、边缘与角点

## 1. 模块目标

理解二维图像的局部变化，稳定提取边缘、方向和角点，为分割、匹配与对象分析提供局部结构。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 04.1 | 一阶差分 | 水平与垂直变化、前向和中心差分 | 在阶跃与斜坡图上计算差分 |
| 04.2 | Sobel | 平滑加微分、方向响应 | 测试水平和垂直边缘 |
| 04.3 | Scharr | 更准确的局部方向响应 | 与 Sobel 比较 |
| 04.4 | 梯度幅值与方向 | gx、gy、幅值、角度和归一化 | 显示方向分布 |
| 04.5 | Laplacian | 二阶变化和噪声敏感性 | 比较平滑前后结果 |
| 04.6 | Canny | 预平滑、梯度、非极大值抑制和双阈值 | 分步观察中间结果 |
| 04.7 | Harris 角点 | 局部结构矩阵和角点响应 | 在棋盘和普通图像上测试 |
| 04.8 | Shi-Tomasi | 最小特征值和优质角点 | 与 Harris 比较 |
| 04.9 | 尺度与稳定性 | 平滑尺度、目标尺寸和重复定位 | 噪声扰动下重复检测 |
| 04.10 | 边缘评价 | Precision、Recall、边界距离和连通性 | 与合成真值比较 |

## 3. 关键认识

- 边缘是局部强变化，不自动等于对象轮廓。
- 噪声也会产生高梯度，因此检测前通常需要适度平滑。
- 平滑尺度决定观察尺度，阈值决定检测灵敏度。
- 角点适合定位和匹配，但低纹理区域可能没有稳定角点。
- 边缘数量增加不一定代表效果更好。

## 4. 模块产出

- 不同方向、模糊程度和噪声水平的合成图像。
- Sobel、Scharr、Laplacian 与 Canny 对比。
- Harris 与 Shi-Tomasi 角点对比。
- 参数—边界误差—重复定位误差表。

## 5. 模块验收

- 能解释梯度幅值和方向。
- 能描述 Canny 的完整流程。
- 能根据目标尺寸选择尺度。
- 能使用边界和重复定位指标评价结果。
