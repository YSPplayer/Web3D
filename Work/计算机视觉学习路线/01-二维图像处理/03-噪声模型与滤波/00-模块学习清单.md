# 模块 03：噪声模型与滤波

## 1. 模块目标

识别常见二维图像噪声和采集伪影，理解滤波器怎样改变像素，并通过指标在去噪与细节保留之间进行选择。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 03.1 | 噪声辨认 | Gaussian、脉冲、散斑、条纹、量化和压缩伪影 | 分别向干净图像添加噪声 |
| 03.2 | 邻域与卷积核 | 核大小、权重、锚点和局部加权 | 手工计算一个小区域 |
| 03.3 | 边界处理 | 常量、复制、反射和周期边界 | 比较图像四周的滤波结果 |
| 03.4 | 均值与方框滤波 | 局部平均、去噪和边缘模糊 | 改变核尺寸 |
| 03.5 | Gaussian 滤波 | sigma、核大小、尺度和可分离计算 | 比较多个 sigma |
| 03.6 | 中值滤波 | 排序统计和脉冲噪声 | 与均值滤波对比 |
| 03.7 | 双边滤波 | 空间距离、值域距离和保边 | 比较平坦区与边缘 |
| 03.8 | 非局部均值 | 相似块、重复纹理和计算成本 | 在重复纹理图上测试 |
| 03.9 | 锐化与高频 | 反锐化、边缘增强和噪声放大 | 比较锐化前后 |
| 03.10 | 滤波评价 | RMSE、PSNR、SSIM、边缘偏移和纹理保持 | 参数—指标曲线 |

## 3. 推荐实验顺序

1. 准备带已知真值的干净图像。
2. 每次只加入一种噪声。
3. 每次只改变一种滤波器或一个参数。
4. 同时测量噪声残差和边缘、纹理损失。
5. 最后才将候选方法应用到真实图像。

## 4. 关键认识

- 不同噪声没有统一最佳滤波器。
- 核尺寸决定观察尺度，越大并不一定越好。
- Gaussian sigma 具有尺度意义。
- 中值滤波擅长处理孤立脉冲，但也会改变细小结构。
- 边界模式会影响靠近图像边缘的结果。
- “更平滑”不是充分的去噪证据。

## 5. 模块产出

- 噪声类型辨认表。
- 至少五种滤波方法对比。
- 参数—噪声残差—细节损失表。
- 滤波选择决策表。
- 至少三个过度滤波失败样本。

## 6. 模块验收

- 能根据噪声特性提出候选方法。
- 能解释核大小、sigma 和边界模式。
- 能使用数值指标评价滤波。
- 能发现真实边缘或细纹理被破坏的情况。
