# 模块 11：模型评价与推理

## 1. 模块目标

证明二维视觉算法在独立数据上有效，并保证训练阶段与实际推理阶段的输入、输出和性能一致。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 11.1 | 数据划分审计 | 主体、批次、时间和近重复样本 | 检查训练测试交叉 |
| 11.2 | 分类指标 | 混淆矩阵、Precision、Recall、F1、ROC 和 PR | 比较不同阈值 |
| 11.3 | 分割指标 | IoU、Dice、边界距离和对象级指标 | 比较大目标与小目标 |
| 11.4 | 检测指标 | IoU 匹配、Precision/Recall 和 mAP | 检查不同尺寸对象 |
| 11.5 | 置信度与阈值 | 分数分布、校准和拒识 | 选择业务阈值 |
| 11.6 | 鲁棒性 | 亮度、噪声、模糊、压缩和遮挡 | 构造扰动测试集 |
| 11.7 | 错误分类 | 数据问题、标签问题、模型问题和域变化 | 建立错误样本表 |
| 11.8 | 推理预处理 | resize、颜色、通道、归一化和 batch | 对照训练配置 |
| 11.9 | 模型导出 | PyTorch 到 ONNX、固定与动态尺寸 | 导出并加载模型 |
| 11.10 | 一致性检查 | 中间输入、最终输出和容差 | 比较两种运行方式 |
| 11.11 | 性能基线 | warm-up、延迟、吞吐量和内存 | 多次重复测量 |
| 11.12 | 精度与性能权衡 | FP32、FP16、量化和批处理 | 比较精度变化 |

## 3. 最低评价要求

- 测试集与训练过程完全隔离。
- 保存测试样本标识和模型版本。
- 同时报告总体指标和分组指标。
- 保存漏检、误检和低置信度样本。
- 给出阈值选择依据。
- 推理前处理与训练前处理逐项一致。

## 4. 推理一致性检查

逐项对比：

- 输入文件解码结果。
- resize 与插值方式。
- RGB/BGR 顺序。
- dtype 与数值范围。
- 均值和标准差。
- 输出张量定义。
- 后处理阈值和坐标映射。
- 最终类别、掩膜或框。

## 5. 模块产出

- 数据划分审计表。
- 任务指标报告。
- 鲁棒性测试矩阵。
- 错误样本图库。
- 模型导出与一致性报告。
- 延迟、吞吐量和内存报告。

## 6. 模块验收

- 能证明测试集没有泄漏。
- 能根据业务目标选择指标和阈值。
- 能复现训练框架与部署框架结果。
- 能先建立性能基线，再进行优化。
- 能明确报告精度和性能之间的取舍。
