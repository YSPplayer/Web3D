# 模块 08：二维变换、匹配与图像对齐

## 1. 模块目标

学习两幅二维图像之间的平移、旋转、尺度、仿射和透视关系，并通过模板、相位或局部特征估计变换。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 08.1 | 平移与旋转 | 坐标中心、方向和边界区域 | 对规则图形施加已知变换 |
| 08.2 | 尺度与仿射 | 缩放、剪切、平行关系和自由度 | 观察不同变换模型 |
| 08.3 | 透视变换 | 四点映射、单应矩阵和适用条件 | 校正倾斜矩形 |
| 08.4 | 图像重采样 | 最近邻、双线性、三次插值和无效边界 | 比较细线与纹理变化 |
| 08.5 | 模板匹配 | 相似度、搜索区域、尺度和旋转限制 | 在大图中定位模板 |
| 08.6 | 相位相关 | 周期边界和亚像素平移 | 恢复已知平移 |
| 08.7 | 局部特征匹配 | 关键点、描述子、距离和候选对应 | 可视化匹配点 |
| 08.8 | 匹配筛选 | 最近邻、ratio test 和交叉检查 | 比较错误匹配比例 |
| 08.9 | RANSAC 估计 | 最小样本、内点阈值和随机迭代 | 在外点中恢复变换 |
| 08.10 | 图像 warp 与拼接 | 反向映射、重叠、接缝和融合 | 完成双图对齐 |
| 08.11 | 对齐评价 | 控制点误差、重叠区残差和已知变换误差 | 输出误差报告 |

## 3. 关键认识

- 对齐前应先选择最简单且足够的变换模型。
- 模板匹配适合外观变化较小的情况。
- 相位相关主要解决平移问题。
- 局部特征适合更大的尺度、旋转或局部遮挡变化。
- RANSAC 只能从候选对应中寻找一致关系。
- warp 会重采样图像，可能改变细节和灰度。
- 接缝不明显不代表对齐误差小。

## 4. 模块产出

- 已知平移、旋转、尺度、仿射和透视变换样本。
- 模板、相位和特征方法对比。
- RANSAC 内点与外点可视化。
- 不同插值方法对比。
- 对齐误差和运行时间报告。

## 5. 模块验收

- 能根据图像关系选择变换模型。
- 能恢复合成数据中的已知变换。
- 能解释匹配筛选与 RANSAC。
- 能量化对齐误差和重采样影响。
