# 模块 05：阈值与区域分割

## 1. 模块目标

把连续像素值转换成前景、背景或多个目标区域，形成可评价、可复现的二维分割基线。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 05.1 | 二值掩膜 | True/False、0/1、前景定义和掩膜运算 | 构造并叠加掩膜 |
| 05.2 | 固定阈值 | 单阈值、上下限和区间阈值 | 扫描阈值 |
| 05.3 | 直方图选阈值 | 单峰、双峰、长尾和异常值 | 对照直方图选择阈值 |
| 05.4 | Otsu | 类间差异和全局分布假设 | 比较适用与不适用图像 |
| 05.5 | 自适应阈值 | 局部窗口、亮度不均和偏置参数 | 在渐变照明图像上测试 |
| 05.6 | 颜色范围分割 | HSV/Lab 范围和多通道条件 | 分离特定颜色目标 |
| 05.7 | 多特征规则 | 灰度、颜色、梯度和位置组合 | 构造可解释分割规则 |
| 05.8 | 区域生长 | 种子、相似性和连通约束 | 改变种子与容差 |
| 05.9 | 分割指标 | 混淆矩阵、Precision、Recall、IoU 和 Dice | 与人工真值比较 |
| 05.10 | 阈值稳定性 | 样本变化、噪声和亮度漂移 | 多图像指标分布 |

## 3. 关键认识

- 阈值是一条决策规则，不是固定魔法数字。
- 自动阈值同样依赖数据分布假设。
- 分割前必须明确前景是什么。
- 像素级指标高不代表小对象一定被检出。
- 阈值需要在独立样本上验证稳定性。

## 4. 模块产出

- 阈值扫描与指标曲线。
- 固定、Otsu、自适应和颜色阈值对比。
- 一套多特征分割规则。
- 漏检、误检、边界偏移和区域断裂案例。

## 5. 模块验收

- 能为阈值选择提供数据依据。
- 能正确计算主要分割指标。
- 能区分像素级与对象级效果。
- 能说明方法在亮度或样本变化下的失效条件。
