# 模块 02：灰度、颜色与图像增强

## 1. 模块目标

理解二维图像的亮度和颜色表达，能够改善可观察性，同时明确哪些操作只用于显示，哪些操作会改变后续算法输入。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 02.1 | 灰度转换 | 通道加权、亮度含义和简单平均的区别 | 比较多种灰度转换 |
| 02.2 | RGB 与 BGR | 通道顺序、读写链路和颜色错误 | 交换通道并观察结果 |
| 02.3 | HSV/HSL | 色相、饱和度和明度 | 按颜色区域构造掩膜 |
| 02.4 | Lab | 感知亮度和颜色分量 | 比较亮度增强对颜色的影响 |
| 02.5 | 直方图 | 分布、峰、长尾、饱和和动态范围 | 比较全图与 ROI 直方图 |
| 02.6 | 线性映射 | 增益、偏置、归一化和裁剪 | 改变亮度与对比度 |
| 02.7 | Gamma 变换 | 非线性亮度映射 | 比较暗部与亮部细节 |
| 02.8 | 直方图均衡化 | 全局分布重排及其副作用 | 在低对比图像上测试 |
| 02.9 | CLAHE | 局部直方图、窗口和限制参数 | 比较全局与局部增强 |
| 02.10 | 颜色校正基础 | 白平衡、色偏和采集一致性 | 对不同色温图像做简单比较 |
| 02.11 | 增强评价 | 可见性、饱和像素、噪声放大和任务指标 | 建立增强前后对比表 |

## 3. 关键认识

- 灰度转换不是简单删除颜色，而是根据通道构造新的亮度值。
- 自动对比度通常会改变不同图像之间的可比性。
- Gamma、均衡化和 CLAHE 可能放大噪声。
- 显示增强结果不能覆盖原始图像。
- 对识别任务有帮助的增强，不一定适合定量灰度测量。

## 4. 模块产出

- RGB/BGR 和不同颜色空间对比。
- 全图与 ROI 直方图。
- 线性、Gamma、均衡化和 CLAHE 参数对比。
- 饱和比例、对比度和下游效果记录。
- 一份“显示增强与算法预处理的边界”说明。

## 5. 模块验收

- 能正确选择颜色空间。
- 能解释 Gamma 和直方图均衡化的区别。
- 能发现增强导致的饱和和噪声放大。
- 能分别保存原始图像、算法输入和显示图。
