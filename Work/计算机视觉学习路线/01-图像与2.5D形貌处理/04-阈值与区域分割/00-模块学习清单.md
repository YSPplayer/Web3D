# 模块 04：阈值与区域分割

## 1. 模块目标

把连续像素值转换成目标、背景或多个区域，并建立可评价、可复现的分割基线。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 04.1 | 二值掩膜 | True/False、0/1、前景定义和掩膜运算 | 构造并叠加显示掩膜 |
| 04.2 | 固定阈值 | 上下限、单阈值和区间阈值 | 扫描阈值并记录指标 |
| 04.3 | 直方图辅助选阈值 | 单峰、双峰、长尾和异常值 | 对照直方图选择候选阈值 |
| 04.4 | Otsu | 类间方差和全局阈值假设 | 比较双峰与非双峰数据 |
| 04.5 | 自适应阈值 | 局部窗口、亮度不均和参数尺度 | 在渐变照明图像上测试 |
| 04.6 | 多通道规则 | 颜色、梯度、高度和组合条件 | 构造多条件缺陷掩膜 |
| 04.7 | 区域生长 | 种子、相似性和连通约束 | 测试种子与容差变化 |
| 04.8 | 分割评价 | 混淆矩阵、Precision、Recall、IoU、Dice | 与合成真值对比 |
| 04.9 | 阈值稳定性 | 批次变化、噪声和数据漂移 | 在多样本上绘制指标分布 |

## 3. 关键认识

- 阈值是一条决策规则，不是固定魔法数字。
- 自动阈值也依赖数据分布假设。
- 图像级随机切块可能造成训练或评价数据泄漏。
- 像素指标高不代表小目标或关键缺陷一定被识别。
- 分割输出必须明确前景定义和无效区域处理。

## 4. 模块产出

- 阈值扫描与指标曲线。
- 固定阈值、Otsu 和自适应阈值对比。
- 至少一套多条件分割规则。
- 失败样本分类：漏检、误检、边界偏移和区域断裂。

## 5. 模块验收

- 能为阈值选择提供数据依据。
- 能正确计算 IoU、Dice、Precision 和 Recall。
- 能区分像素级与对象级效果。
- 能说明方法在光照、批次或高度范围变化下的失效条件。
