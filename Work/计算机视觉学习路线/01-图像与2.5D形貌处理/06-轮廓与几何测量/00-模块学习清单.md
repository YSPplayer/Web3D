# 模块 06：轮廓与几何测量

## 1. 模块目标

从区域掩膜中得到有拓扑、方向和物理尺度的轮廓与几何量，并理解像素化和边界误差如何影响测量。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 06.1 | 轮廓提取 | 边界跟踪、闭合轮廓和点序 | 从简单二值形状提取轮廓 |
| 06.2 | 轮廓层级 | 外轮廓、孔洞、父子关系 | 处理带孔圆环和嵌套区域 |
| 06.3 | 面积与周长 | 像素面积、轮廓积分和离散误差 | 比较理论圆与像素圆 |
| 06.4 | 矩与质心 | 空间矩、质心和主方向 | 计算不规则目标方向 |
| 06.5 | 外接形状 | 轴对齐框、最小旋转框和最小包围圆 | 比较旋转目标的尺寸 |
| 06.6 | 凸包与凹陷 | convex hull、solidity 和凸缺陷 | 描述凹形轮廓 |
| 06.7 | 直线/圆/椭圆拟合 | 拟合残差、内点和几何参数 | 对带噪轮廓恢复参数 |
| 06.8 | 像素到物理单位 | 像素间距、非等距轴和面积换算 | 输出毫米或微米尺寸 |
| 06.9 | 亚像素测量 | 边缘插值、拟合和重复性 | 比较整数像素与拟合结果 |
| 06.10 | 测量不确定性 | 边界漂移、标定误差和重复采样 | 多次扰动后统计尺寸分布 |

## 3. 关键认识

- findContours 得到的是离散边界，不等于连续真实轮廓。
- 周长通常比面积更容易受到像素化和噪声影响。
- 外接矩形的定义不同，得到的宽高含义也不同。
- 没有像素间距和标定，尺寸只能写成像素单位。
- 轮廓测量要报告重复性，不能只给单次结果。

## 4. 模块产出

- 一份轮廓属性表。
- 圆、矩形、椭圆和不规则目标的合成测量实验。
- 像素分辨率与测量误差曲线。
- 物理单位换算和误差来源说明。

## 5. 模块验收

- 能正确处理外轮廓与孔洞。
- 能选择合适的面积、方向和尺寸定义。
- 能将结果转换成物理单位。
- 能通过重复实验估计轮廓测量的稳定性。
