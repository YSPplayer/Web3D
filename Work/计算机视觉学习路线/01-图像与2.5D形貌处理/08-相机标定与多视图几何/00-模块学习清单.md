# 模块 08：相机标定与多视图几何

## 1. 模块目标

建立三维点、相机和二维像素之间的坐标链，理解标定、畸变、透视校正、双目和深度数据的来源。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 08.1 | 针孔相机模型 | 焦距、主点、透视除法 | 投影简单三维点 |
| 08.2 | 坐标链 | 世界、相机、归一化成像平面和像素坐标 | 手工追踪一个点的变换 |
| 08.3 | 内参与外参 | 相机自身参数和相机位姿 | 分析参数变化对图像的影响 |
| 08.4 | 畸变模型 | 径向畸变和切向畸变 | 模拟并校正畸变网格 |
| 08.5 | 标定数据采集 | 标定板、姿态覆盖、清晰度和角点分布 | 设计一组标定拍摄方案 |
| 08.6 | 相机标定 | 角点、参数估计和重投影误差 | 完成单目标定 |
| 08.7 | 标定验证 | 独立图像、空间分布和残差图 | 检查是否只在局部准确 |
| 08.8 | 透视矫正 | 平面单应性和鸟瞰变换 | 校正倾斜平面 |
| 08.9 | 极线几何 | 基础矩阵、本质矩阵和对应约束 | 显示对应极线 |
| 08.10 | 双目与深度 | 视差、基线、焦距和深度关系 | 从合成视差计算深度 |

## 3. 关键认识

- 内参描述相机成像，外参描述坐标系之间的位姿。
- 低平均重投影误差不保证所有图像区域都准确。
- 标定图像必须覆盖不同位置、距离和姿态。
- 双目深度误差会随距离和视差精度变化。
- 相机标定结果需要版本化，并与镜头、焦距和分辨率绑定。

## 4. 模块产出

- 相机坐标链示意图。
- 标定采集检查清单。
- 内参、畸变参数和每张图像的重投影误差。
- 一组畸变校正与透视矫正前后对比。

## 5. 模块验收

- 能描述三维点投影到像素的完整步骤。
- 能区分内参与外参。
- 能发现覆盖不足或误差分布异常的标定。
- 能说明视差、基线与深度精度的关系。
