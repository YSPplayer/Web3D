# 模块 09：2.5D 高度图形貌处理

## 1. 模块目标

把前面学习的图像处理方法扩展为具有物理单位和几何意义的高度图处理流程，完成表面基准、局部形貌、缺陷和体积的定量分析。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 09.1 | 高度图数据模型 | x/y 网格、z 值、单位、方向和有效掩膜 | 建立标准高度图数据说明 |
| 09.2 | 质量检查 | 饱和、离群、条纹、台阶、缺失和边界伪影 | 对异常模式分类 |
| 09.3 | 基准面与趋势 | 平面、低阶趋势和参考区域 | 从斜面加缺陷中恢复缺陷 |
| 09.4 | 曲面基准 | 圆柱、球面或其他名义曲面 | 拟合并去除已知曲面 |
| 09.5 | 鲁棒拟合 | 缺陷对基准拟合的污染、掩膜和迭代剔除 | 比较普通与鲁棒拟合 |
| 09.6 | 缺失值与插值 | 最近邻、线性、样条、修复范围和不确定性 | 在已知真值上遮挡再恢复 |
| 09.7 | 梯度与法向 | 像素间距、斜率和单位一致性 | 在已知倾角表面验证 |
| 09.8 | 曲率与局部形状 | 主曲率、平均/Gaussian 曲率和窗口尺度 | 区分峰、坑、脊和鞍点 |
| 09.9 | 尺度分离 | 形状、波纹与粗糙成分 | 比较不同滤波尺度 |
| 09.10 | 缺陷分割 | 高度、深度、梯度、曲率和组合规则 | 建立传统缺陷检测基线 |
| 09.11 | 定量测量 | 深度、高度、面积、体积、方向和位置 | 与合成真值比较 |
| 09.12 | 高度图对齐 | 平移、旋转、重叠区和高度偏置 | 对齐重复测量数据 |
| 09.13 | 不确定度与重复性 | 重复采集、处理参数和测量波动 | 输出重复性统计 |

## 3. 处理顺序

    数据与元数据检查
      → 有效区域掩膜
      → 异常值和采集伪影识别
      → 基准面或名义曲面处理
      → 必要的滤波或尺度分离
      → 梯度、法向、曲率等特征
      → 缺陷区域提取
      → 面积、深度、体积等定量测量
      → 重复性和失败样本分析

## 4. 关键认识

- 亮度图算法可以复用，但 z 值不是亮度，具有真实单位。
- x/y/z 单位比例错误会直接导致法向和曲率错误。
- 去基准会改变低频形状，必须明确被去除的对象是什么。
- 插值值和 AI 补全值不能标记成实测值。
- 滤波尺度应与需要保留或去除的物理特征尺度对应。
- 单张漂亮的伪彩图不能证明算法准确。

## 5. 模块产出

- 一份高度图标准数据说明。
- 平面和曲面去基准实验。
- 缺失区域插值误差实验。
- 梯度、法向、曲率和缺陷掩膜图。
- 面积、深度和体积真值对比。
- 一份重复性与不确定度说明。

## 6. 模块验收

- 能保持并解释所有物理单位和坐标约定。
- 能选择适合的基准并说明其影响。
- 能分别标识实测区和插值区。
- 能使用合成真值或重复测量评价处理结果。
- 能形成一条可复现的形貌处理流水线。
