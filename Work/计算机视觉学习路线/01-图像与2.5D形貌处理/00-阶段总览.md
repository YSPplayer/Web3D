# 图像与 2.5D 形貌处理：阶段总览

## 1. 阶段定位

这是跳过独立数学阶段后的第一个正式学习阶段。它从图像和高度图的真实数据结构开始，逐步学习滤波、边缘、分割、形态学、轮廓、匹配、标定和形貌测量。

这一阶段不追求“学完 OpenCV”，而是建立以下完整能力：

    原始数据
      → 质量检查
      → 预处理与滤波
      → 特征或区域提取
      → 轮廓与几何测量
      → 对齐与标定
      → 2.5D 形貌分析
      → 指标评价与结果报告

## 2. 总学习目标

完成本阶段后，应当能够：

1. 正确读取和解释 8 位、16 位及浮点图像或高度图。
2. 根据噪声性质选择滤波方法，而不是依靠视觉偏好试参数。
3. 使用梯度、边缘、阈值、形态学和区域方法得到稳定掩膜。
4. 从掩膜与轮廓计算面积、周长、方向和具有物理单位的尺寸。
5. 使用模板、相位或局部特征完成图像对齐。
6. 理解相机标定、畸变、透视投影和多视图深度的基本关系。
7. 对高度图进行去基准、异常值处理、插值、法向、曲率和缺陷分析。
8. 建立传统算法基线，并通过指标和失败样本评价结果。

## 3. 学习原则

### 3.1 原始值优先

- 原始数据与显示数据分开保存。
- 不在不知情的情况下转成 8 位图。
- 不用显示出来的颜色值代替真实高度值。
- 不把 NaN 或缺失值默认当作 0。

### 3.2 每个算法都要回答五个问题

1. 它解决什么问题？
2. 它对数据有什么假设？
3. 参数控制什么现象？
4. 哪些真实信息可能被它改变？
5. 用什么指标证明处理有效？

### 3.3 合成数据先行

优先使用带已知真值的合成图像或高度图学习算法，再使用真实数据验证。合成数据便于单独控制噪声、边缘、缺失值、目标尺寸和形貌。

### 3.4 一次只改变一个变量

比较算法时，一次只改变滤波器、核大小、阈值或噪声强度中的一个条件，并记录结果。

### 3.5 及时补充必要数学

本阶段不设置独立数学课程，但遇到以下内容时要做小范围补充：

- 学卷积时补充核与加权和。
- 学梯度时补充有限差分。
- 学相位相关时补充傅里叶变换的直观含义。
- 学拟合时补充最小二乘。
- 学标定时补充矩阵变换和坐标系。

## 4. 建议工具

- Python：组织实验。
- NumPy：检查和操作数组。
- OpenCV：图像处理与计算机视觉。
- Matplotlib：显示图像、直方图和对比结果。
- tifffile 或 imageio：读取保留位深的图像数据。
- Jupyter Notebook 或普通 Python 脚本：记录可重复实验。

工具只是实现载体，学习记录必须保留算法目标、数据条件、参数含义和评价结论。

## 5. 阶段产出

每个模块至少保留：

- 一份模块学习记录。
- 一组带已知条件的合成数据实验。
- 一组真实数据实验。
- 参数对比表。
- 失败样本。
- 一段可复述的结论。

最终完成一个“高度图或图像形貌缺陷分析”综合项目。
