# 模块 03：梯度与边缘

## 1. 模块目标

理解局部变化率如何对应边缘、坡度和表面方向，并能在不同噪声与尺度下稳定提取有意义的边界。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 03.1 | 一阶差分 | 水平、垂直变化与有限差分 | 在斜坡和阶跃图上计算差分 |
| 03.2 | Sobel/Scharr | 平滑加微分、方向响应 | 测试水平、垂直和斜向边缘 |
| 03.3 | 梯度幅值与方向 | gx、gy、幅值和角度 | 用方向颜色显示梯度 |
| 03.4 | Laplacian | 二阶变化、零交叉和噪声敏感性 | 比较平滑前后的 Laplacian |
| 03.5 | Canny | 去噪、梯度、非极大值抑制和双阈值 | 分步观察 Canny 中间结果 |
| 03.6 | 多尺度边缘 | 模糊尺度与边缘定位 | 比较细小缺陷和大轮廓 |
| 03.7 | 亚像素与边缘稳定性 | 像素量化、拟合和重复定位 | 测量边缘随噪声的漂移 |
| 03.8 | 高度图梯度 | x/y 像素间距、坡度和单位 | 在已知斜率表面验证梯度 |
| 03.9 | 边缘评价 | Precision、Recall、边界距离和连通性 | 与人工或合成真值比较 |

## 3. 关键认识

- 边缘是特定尺度上的强变化，不等于物体轮廓。
- 噪声也会产生高梯度，因此边缘检测通常需要适度预平滑。
- 阈值决定检测灵敏度，平滑尺度决定观察尺度。
- 高度图的梯度必须考虑 x、y 和 z 的实际单位。
- 边缘图通常只是中间结果，还需要分割、形态学或轮廓连接。

## 4. 模块产出

- 不同方向和尺度的合成边缘集。
- Sobel、Scharr、Laplacian 和 Canny 对比。
- 阈值与边界误差曲线。
- 一组噪声导致假边缘的失败样本。

## 5. 模块验收

- 能说明梯度幅值和方向的意义。
- 能解释 Canny 的主要步骤。
- 能基于目标尺寸选择平滑尺度。
- 能使用边界指标而不是只看边缘数量。
