# 模块 05：形态学与连通区域

## 1. 模块目标

使用结构元素和拓扑关系清理分割结果，并把像素级掩膜转换成可管理的对象级区域。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 05.1 | 结构元素 | 形状、尺寸、方向和观察尺度 | 比较圆、方、十字和线形核 |
| 05.2 | 腐蚀与膨胀 | 边界收缩、扩张和小区域变化 | 观察目标尺寸变化 |
| 05.3 | 开运算与闭运算 | 去除小点、连接间隙和形状偏差 | 在带孔洞掩膜上测试 |
| 05.4 | Top-hat/Black-hat | 小亮结构和小暗结构提取 | 提取局部峰或凹坑 |
| 05.5 | 连通域 | 4/8 连通、标签、面积和外接框 | 提取多个独立对象 |
| 05.6 | 距离变换 | 到边界的距离和中心结构 | 分析目标厚度与中心 |
| 05.7 | 骨架化 | 中轴、分支和拓扑 | 提取细长缺陷中心线 |
| 05.8 | 分水岭 | 距离峰、标记和粘连目标分离 | 分离互相接触的对象 |
| 05.9 | 规则化与过滤 | 面积、长宽比、位置和形状规则 | 清理对象级误检 |

## 3. 关键认识

- 结构元素的大小直接定义被保留或删除的特征尺度。
- 形态学会改变边界和面积，不能处理后仍沿用原始测量结论。
- 连通规则会改变对象数量。
- 清理掩膜的目标应是去除已知伪影，而不是让图像更好看。

## 4. 模块产出

- 结构元素选型表。
- 每种形态学操作的前后对比。
- 连通区域属性表。
- 一组因过度开闭运算导致目标消失或粘连的失败样本。

## 5. 模块验收

- 能根据目标的物理尺寸选择结构元素。
- 能解释 4 连通与 8 连通的对象差异。
- 能量化形态学前后的面积、周长和对象数量变化。
- 能分离或过滤目标，同时报告对边界的影响。
