# 模块 07：特征匹配与图像对齐

## 1. 模块目标

学习从两幅图像中寻找对应关系并估计二维变换，为图像拼接、重复测量对齐和多视图几何建立基础。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 07.1 | 变换模型 | 平移、旋转、尺度、仿射和单应性 | 对合成网格施加不同变换 |
| 07.2 | 模板匹配 | 相似度、搜索区域和尺度限制 | 在大图中定位小模板 |
| 07.3 | 相位相关 | 频域平移估计和周期边界 | 恢复已知亚像素平移 |
| 07.4 | 角点与局部特征 | Harris、Shi-Tomasi、SIFT、ORB | 比较纹理与低纹理区域 |
| 07.5 | 描述子匹配 | 距离、最近邻、ratio test 和交叉检查 | 统计正确与错误匹配 |
| 07.6 | RANSAC | 最小样本、内点、阈值和迭代 | 在错误匹配中恢复变换 |
| 07.7 | 仿射与单应估计 | 自由度、适用场景和退化情况 | 比较平面与非平面对象 |
| 07.8 | 图像变换与重采样 | 反向映射、插值和无效边界 | 比较最近邻、双线性和三次插值 |
| 07.9 | 拼接与融合 | 重叠区、接缝、曝光和融合 | 完成简单双图拼接 |
| 07.10 | 对齐评价 | 已知变换误差、重投影误差和重叠区残差 | 建立对齐误差报告 |

## 3. 关键认识

- 对齐之前要先选择正确的变换模型。
- 模板匹配适合变化有限的场景，局部特征适合更大视角或尺度变化。
- RANSAC 只能在候选对应中剔除外点，不能修复完全缺失的正确匹配。
- 图像 warp 会进行重采样，可能改变高频细节和测量值。
- 拼接视觉自然不等于几何对齐准确。

## 4. 模块产出

- 已知平移、旋转、尺度和透视变换的合成数据集。
- 模板、相位和特征方法对比。
- 匹配点和 RANSAC 内外点可视化。
- 变换误差与重叠区残差报告。

## 5. 模块验收

- 能根据场景选择平移、仿射或单应模型。
- 能解释局部特征匹配的完整流程。
- 能用真值或控制点评价估计变换。
- 能报告重采样和融合对原始数值的影响。
