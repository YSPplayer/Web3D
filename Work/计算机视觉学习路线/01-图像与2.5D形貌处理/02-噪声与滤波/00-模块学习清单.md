# 模块 02：噪声与滤波

## 1. 模块目标

认识不同噪声和采集伪影，理解不同滤波器改变数据的方式，并能通过指标选择兼顾去噪和细节保留的方案。

## 2. 小学习单元

| 编号 | 学习项 | 核心内容 | 最小实验 |
|---|---|---|---|
| 02.1 | 噪声与真实细节 | Gaussian、脉冲、散斑、条纹、量化、缺失点和设备伪影 | 向合成图像分别添加不同噪声 |
| 02.2 | 邻域、核与边界 | 核大小、权重、步长、padding、边界复制和反射 | 比较同一滤波器的不同边界处理 |
| 02.3 | 均值与方框滤波 | 局部平均、平滑与边缘模糊 | 改变核尺寸并测量边缘位移 |
| 02.4 | Gaussian 滤波 | sigma、核大小、尺度与可分离卷积 | 比较不同 sigma 的噪声和细节变化 |
| 02.5 | 中值滤波 | 排序统计、脉冲噪声和边缘保持 | 对椒盐噪声比较均值与中值 |
| 02.6 | 双边与保边滤波 | 空间距离、值域距离和保边机制 | 比较平坦区去噪与边缘保留 |
| 02.7 | 非局部去噪 | 相似块、非局部均值及计算成本 | 在重复纹理数据上观察效果 |
| 02.8 | 高频与锐化 | 高通、反锐化掩膜及噪声放大 | 比较锐化前后边缘与噪声 |
| 02.9 | 形貌数据滤波 | z 值、无效掩膜、尺度和真实峰谷保护 | 在已知峰高和坑深的高度图上测试 |
| 02.10 | 滤波评价 | RMSE、PSNR、SSIM、边缘偏移、峰谷误差和重复性 | 建立参数—指标对比表 |

## 3. 推荐学习顺序

1. 先构造带真值的干净数据。
2. 分别添加一种噪声。
3. 每次只测试一种滤波器。
4. 每次只改变一个参数。
5. 同时评价去噪能力和特征损失。
6. 最后才在真实数据上选择参数。

## 4. 必须理解的必要概念

- 卷积核是邻域值的加权组合。
- 核越大通常平滑越强，但空间细节损失越多。
- sigma 是尺度参数，不只是“强度滑块”。
- 边界处理会改变靠近图像边缘的结果。
- 不同噪声对应不同统计特性，不存在通用最佳滤波器。
- 对测量数据而言，峰高、坑深、边缘位置和面积可能比视觉平滑更重要。

## 5. 模块产出

- 噪声类型辨认表。
- 五种以上滤波器的对比实验。
- 参数—噪声残差—特征损失表。
- 一份滤波选型决策表。
- 一组“滤波过度”的失败样本。

## 6. 模块验收

- 能根据噪声特性提出首选滤波方案。
- 能解释核大小、sigma 和边界模式的含义。
- 能用数值指标证明滤波有效。
- 能发现并报告真实边缘、峰值或坑深被滤波改变的情况。
- 不使用“看起来更平滑”作为唯一结论。
